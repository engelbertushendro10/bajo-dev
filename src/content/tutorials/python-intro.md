# Pengenalan Python & Instalasi

Python adalah bahasa pemrograman populer yang mudah dipelajari. Banyak digunakan untuk web development, data science, dan otomatisasi.

## Kelebihan Python

- Sintaks mudah seperti bahasa Inggris
- Banyak library (pustaka) siap pakai
- Komunitas besar
- Cocok untuk pemula

## Instalasi Python

1. Buka link : [python.org](https://python.org)
2. Download versi terbaru (3.11+)
3. Jalankan installer → centang **Add Python to PATH**
4. Buka terminal/CMD, ketik:

```bash
python --version
```

Jika muncul versi Python, berarti instalasi berhasil! Selamat belajar Python!

# Menjalankan Kode Python

Setelah Python terinstal, kamu bisa menjalankan kode Python dengan beberapa cara:

1. **Python REPL**: Buka terminal/CMD, ketik `python` lalu tekan Enter. Kamu bisa langsung mengetik kode Python di sana.
2. **File Python**: Buat file dengan ekstensi `.py`, misalnya `hello.py`, lalu isi dengan kode Python. Jalankan file tersebut dengan perintah:

```bash
python hello.py

```

3. **IDE**: Gunakan Integrated Development Environment (IDE) seperti PyCharm, VS Code, atau Jupyter Notebook untuk menulis dan menjalankan kode Python dengan lebih mudah.

**Contoh Kode Python**

Berikut contoh kode Python sederhana yang mencetak "Hello, World!":

```bash
python print("Hello, World!")

```

Simpan kode di atas dalam file `hello.py` dan jalankan untuk melihat hasilnya. Selamat mencoba!
Dengan Python, kamu bisa membuat berbagai macam aplikasi, mulai dari web, data science, hingga game. Jangan ragu untuk bereksperimen dan belajar lebih dalam!

**Kesimpulan**

Python adalah bahasa pemrograman yang sangat cocok untuk pemula karena sintaksnya yang sederhana dan banyaknya sumber belajar. Dengan mengikuti langkah instalasi di atas, kamu sudah siap untuk mulai belajar Python dan menjelajahi dunia pemrograman!
