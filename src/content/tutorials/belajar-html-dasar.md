# Belajar HTML Dasar untuk Pemula

HTML (HyperText Markup Language) adalah bahasa dasar untuk membuat website. Setiap halaman web yang kamu kunjungi menggunakan HTML.

## Apa itu HTML?

HTML adalah bahasa markup yang digunakan untuk membuat struktur halaman web. Bayangkan HTML seperti kerangka rumah:

- **Tag** seperti `<p>`, `<div>`, `<h1>` adalah material bangunan
- **Atribut** seperti `class`, `id` adalah cat atau dekorasi
- **Konten** adalah isi rumahnya

## Struktur Dasar HTML

Setiap dokumen HTML memiliki struktur seperti ini:

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Judul Halaman</title>
</head>
<body>
    <h1>Halo, Dunia!</h1>
    <p>Ini adalah paragraf pertama saya.</p>
</body>
</html>
